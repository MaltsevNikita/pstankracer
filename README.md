# IRON LAP

Браузерные танковые гонки в эстетике PS1: один заводской круг, настраиваемая дистанция
(1, 3 или 5 кругов), три соперника-бота, бусты, ракеты и мины. Без смертей — попадание
сбивает скорость и разворачивает танк.

## Запуск

```bash
npm install
npm run dev      # http://localhost:4001
npm run build    # tsc --noEmit + vite build → dist/
npm run preview  # статический предпросмотр собранной игры
```

Сборка статическая (`dist/`), серверной части нет.

## Управление

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Газ | `W` / `↑` | `RT` или левый стик вверх |
| Тормоз / назад | `S` / `↓` | `LT` |
| Поворот | `A` `D` / `←` `→` | левый стик, крестовина |
| Огонь (ядро) | `Space` | `A` / `RB` |
| Особое оружие (ракета/мина) | `F` | `X` |
| Ускорение (нитро) | `Tab` | `B` / `LB` |
| Смена камеры | `C` | `Y` |
| Пауза | `Esc` | `Start` |

`Enter` на главном меню запускает заезд.

## Механика

- **Трасса** `ЗАВОДСКОЙ КРУГ` — замкнутый сплайн с двумя горками, поребриками,
  отбойниками и воротами. Срез невозможен: позиция считается по непрерывному
  прогрессу вдоль центральной линии.
- **Старт** — решётка 2×2, отсчёт 3-2-1, дистанция 1, 3 или 5 кругов
  (переключается в настройках, по умолчанию 3).
- **Бусты** — пять плашек на асфальте дают ~2,3 с ускорения. Плюс ручное нитро на
  `Tab`: заряд тратится за ~2 секунды и восстанавливается сам.
- **Пушка** — `Space` стреляет прямым оранжевым ядром по направлению ствола.
  Заряды не ограничены, ядро летит без самонаведения и сбивает скорость при попадании.
- **Особое оружие** — ракеты (самонаводятся на цель впереди) и мины (ставятся за
  кормой) подбираются на трассе и применяются на `F`. Оружие одноразовое, пикапы
  восстанавливаются через 7 секунд.
- **Боты** — три уровня сложности, скорость зависит от кривизны трассы, есть
  лёгкий rubber-band и случайные ошибки.
- **Рекорды** — лучший круг общий, а лучший заезд хранится отдельно для каждой
  дистанции (1, 3, 5 кругов), чтобы короткая гонка не перебивала длинную.
  Всё лежит в `localStorage` (`ironlap.records.v1`), настройки — в
  `ironlap.settings.v1`.

## Визуальный конвейер PS1

- Внутренний буфер 640×360 (или меньше на маленьких экранах), nearest-апскейл.
- Снеппинг вершин в вершинном шейдере (`onBeforeCompile` у материалов сцены).
- Пост-обработка: 5 бит на канал + упорядоченный дизеринг Байера, мягкая
  виньетка, скан-линии.
- Туман, отсутствие сглаживания, `NearestFilter` для всех текстур.
- 24-битная глубина в render target — иначе плоские ленты трассы конфликтуют
  с землёй.

## Структура

```
index.html
src/main.ts               точка входа, жизненный цикл заезда
src/style.css             меню, HUD, CRT-оверлей
src/engine/ps1.ts         WebGL, render target 640×360, пост-эффекты
src/engine/game.ts        фиксированный шаг 60 Гц, гонка, камера, HUD-состояние
src/engine/track.ts       сплайн трассы, меши, декор, поиск ближайшей точки
src/engine/tank.ts        модель танка и аркадная физика
src/engine/ai.ts          боты
src/engine/weapons.ts     пушка (ядра), пикапы, ракеты, мины
src/engine/effects.ts     частицы, вспышки, тряска камеры
src/engine/audio.ts       синтез звука на WebAudio
src/engine/input.ts       клавиатура и Gamepad API
src/ui/hud.ts             HUD и миникарта на canvas
src/ui/ui.ts              меню, настройки, пауза, результаты, рекорды
```

## Отладка

В dev-режиме объект игры доступен как `window.__ironlap` (игрок, трасса,
рендерер, список гонщиков).
